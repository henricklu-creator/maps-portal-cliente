# MAPS — Portal do Cliente

Artefato estático de produção do Portal do Cliente MAPS.

Este repositório contém somente os arquivos públicos já compilados do portal.
Não contém código-fonte, certificados, credenciais privadas ou banco de dados.
O portal utiliza o mesmo Supabase consolidado do FiscalBot, com autenticação,
2FA por WhatsApp e políticas de acesso no servidor.
